## فحص خادم الإنتاج المحلي

شُغّل ناتج standalone على `0.0.0.0:3000`. أعادت المسارات التالية `200` ومحتوى HTML وعنوانًا و`H1` واحدًا:

- `/`, `/en`, `/about`, `/en/about`.
- `/faculties`, `/en/faculties`.
- جميع صفحات الكليات الست بالعربية والإنجليزية: المعلوماتية، هندسة البترول، الصيدلة، الطب البشري، طب الأسنان، وإدارة الأعمال.
- `/services`, `/platform`, `/contact`, `/en/contact`.

أعادت `/robots.txt` الحالة `200 text/plain` و`/sitemap.xml` الحالة `200 application/xml`. يحتوي sitemap على 34 رابطًا أساسيًا، بينها 12 رابط كلية (6 كليات × لغتين). أعاد `/not-a-real-route` و`/faculties/clinical` الحالة `404` بأمان.

## ملفات عامة وSEO

- `favicon-48.png`: `200 image/png`.
- الشعار الرسمي `/Logos/اساسي.png`: `200 image/png`.
- حزمة CSS وحزمة JavaScript المحمّلتان من الصفحة الرئيسية: `200`.
- الصفحة الرئيسية: canonical واحد، بديلان `ar` و`en`، نصا JSON-LD، 11 وسم Open Graph، 4 وسوم Twitter، وصفر نماذج HTML.
- محاكاة طلب HTTP للنطاق القانوني وطلب `www` أعادت كلاهما `308` إلى `https://xn--mgbaab0cxheq.tech/about` من دون منفذ محلي.

## تحقق تجربة الجوال من المصدر

اختبارات العقد تغطي رأس `72px`، الحد الأدنى للمس، درج قائمة جوال مع `100dvh` وطبقة تعتيم وقفل تمرير وEscape وحصر تركيز واستعادة تركيز، إضافةً إلى الحواشي والطباعة المتجاوبة ومسارات الطالب السريعة.

## حدود التحقق

لم يُجرَ في هذه البيئة اختبار بصري تفاعلي على جهاز iOS أو Android فعلي. كما لم يُشغّل Docker محليًا لأن Docker daemon غير متاح محليًا؛ لم يتغير Dockerfile-first، ويظل بناء Coolify هو فحص الحاوية الخارجي التالي.
