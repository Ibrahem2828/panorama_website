# تقرير QA الاستجابة

## نقاط الفحص

- سطح المكتب: لقطة Chrome فعلية للصفحة العربية بعد تحميل CSS والصور؛ الترويسة، البطاقة البصرية، النصوص، الأزرار والتباين ظهرت سليمة.
- الهاتف: محاكاة DevTools بقياس CSS حقيقي `390 × 844` لمسار كلية المعلوماتية.

## نتيجة الهاتف القابلة للقياس

| المقياس | القيمة |
| --- | --- |
| `window.innerWidth` | 390 |
| `documentElement.clientWidth` | 390 |
| `documentElement.scrollWidth` | 390 |
| تمرير أفقي | لا |

كما فتحت القائمة المحمولة كحوار وأغلقت بـ Escape. اللقطة الأولية التي بدا فيها اقتطاع بصري لم تكن قياساً صحيحاً بسبب مقياس واجهة Windows في Chrome headless؛ أعيد الاختبار بمحاكاة DevTools، وهو القياس المعتمد.

## ملاحظات التصميم

- الشبكات تتحول عبر breakpoints، وبطاقات الكليات تحفظ مساحة الشعار باستخدام `object-contain`.
- الترويسة المحمولة تستخدم زر القائمة بدل التنقل الأفقي.
- الأزرار ذات حد أدنى للمساحة اللمسية، والنص العربي يحافظ على RTL.

## خارج نطاق الإثبات

لم يتم اختبار أجهزة iOS أو Android مادية أو متصفحات خارج Chrome. يلزم اختبار قبول على الأجهزة الفعلية قبل إطلاق عام واسع.
