# تدقيق الأداء

## قياس مخبري محلي

تم تشغيل Chrome جديد بلا cache مع تعطيل cache على `http://localhost:3000/`. هذه ليست Core Web Vitals ولا تمثل شبكة الإنتاج أو CDN.

| القياس | القيمة المحلية |
| --- | ---: |
| TTFB | 337ms |
| DOMContentLoaded | 2968ms |
| Load | 3462ms |
| First Paint | 2956ms |
| First Contentful Paint | 3280ms |
| نقل مستند HTML | 20,121 bytes |
| حجم HTML المفكوك | 113,527 bytes |
| ملفات `.next/static` | 50 ملفاً / 1,335,049 bytes |

## القراءة الصحيحة للنتيجة

- القياس بارد ومحلي ويشمل تشغيل Chrome وتحميل الخطوط وطبقة splash؛ لا يستخدم لإعلان هدف إنتاجي متحقق.
- لا توجد صور خارجية أو استدعاءات طرف ثالث أساسية في المسار المختبر.
- الصور تستخدم تحسين Next، وCSS/JS يتم تقديمهما من مخرجات static.
- Nginx المرفق يضع cache immutable لـ `/_next/static/` وgzip، وDocker يبقي الموقع خلف loopback افتراضياً.

## توصيات قبل نشر عام

1. تشغيل Lighthouse وWebPageTest أو RUM على عنوان HTTPS المرحلي بعد تهيئة CDN والشهادة.
2. قياس LCP/INP/CLS على هاتف فعلي وشبكة 4G؛ لا تعتمد هذا القياس المحلي بديلاً.
3. أضف صوراً مستقبلية بالحجم المعتمد و`next/image` فقط، وراجع الأصول الجديدة قبل نشرها.
4. راقب حجم الحزم عند إضافة analytics أو widgets أو خرائط؛ لا توجد حالياً أداة budget آلية في المستودع.
