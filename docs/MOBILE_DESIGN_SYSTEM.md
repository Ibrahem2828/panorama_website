# نظام تصميم الجوال

المصدر التنفيذي للتصميم هو `src/app/globals.css`.

| العنصر | القاعدة الحالية |
| --- | --- |
| حافة المحتوى | `clamp(1rem, 4vw, 2rem)` |
| مساحة القسم | `clamp(3.5rem, 8vw, 7rem)` |
| عنوان الصفحة | `clamp(2.5rem, 10vw, 4rem)` |
| عنوان القسم | `clamp(1.9rem, 7vw, 3rem)` |
| عنوان البطاقة | `clamp(1.25rem, 5vw, 1.65rem)` حيث يُستخدم |
| الأزرار/التحكم | حد أدنى `48px` |
| البطاقات | حشوة `20–24px` في المسارات الأساسية |

تستخدم الواجهة الألوان الدلالية والحدود والظلال المعرفة مسبقًا، ولا تستبدل الهوية البصرية القائمة. الحركات قصيرة، وتحترم `prefers-reduced-motion`.
